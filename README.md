# 프로젝트 이름
LEO_AIR 관리자 시스템

## 📌 프로젝트 소개
본 시스템은 일반 사용자용이 아닌 **각 구청/행정 관계자용**으로 기획된 관리자 시스템입니다.  
따라서 별도의 회원가입 절차는 없으며, **최고 관리자(admin)** 가 직접 계정을 발급하는 구조입니다.
> **웹 시연용 계정**
> URL : http://52.78.84.97:30080/sas
> ID: `admin` / PW: `test`

## 🚀 주요 기능
- 📊 **실시간 데이터 시각화** (미세먼지 등 공공 API 기반)
- 🧩 **사용자 위젯 커스터마이징** (GridStack 적용)
- 🔍 **Elasticsearch 쿼리 편집기** 내장 (Ace Editor 기반)
- ⏱️ **시간 단위별 공공데이터 수집 및 모니터링**
- 🗂️ **게시판 시스템** (공지, 자유, 기술 등)

## 🛠️ 사용 기술
🔸 Frontend
- AngularJS
- ECharts, GridStack.js, AntV
- Bootstrap, Split.js, SweetAlert, AceEditor

🔹 Backend
- Spring MVC
- Elasticsearch 8.17.3

⚙️ DevOps
- Docker, GitHub Actions, Kubernetes(K3s)

## 💡 프로젝트 배경
운영 데이터를 **전문가가 아니어도 쉽게 이해할 수 있도록** 시각화에 집중했습니다.  
또한 사용자가 각자 원하는 정보를 편리하게 볼 수 있도록 **위젯 커스터마이징 기능**을 설계했습니다.  
특히 **모니터링 환경**에서 사용자별로 필요로 하는 **데이터 흐름과 시각화 방식을 자유롭게 구성**할 수 있도록  **직관적이고 유연한 시각화 흐름 설계**에 중점을 두었습니다.
